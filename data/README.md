# Dataset Documentation

This folder contains the datasets required for the **E-commerce Customer Segmentation & Targeted Marketing Analytics** project.

## Data Source

The datasets are sourced from **Dunnhumby – The Complete Journey**.

**Official source:** https://www.dunnhumby.com/source-files/

The Complete Journey dataset provides household-level grocery transaction records, product information, demographic attributes and direct marketing campaign data.

## Dataset Files

The following CSV files are used in this project:

| File Name | Description |
|---|---|
| `transaction_data.csv` | Household-level purchase transaction records |
| `product.csv` | Product details, departments, commodities and brand classifications |
| `hh_demographic.csv` | Household demographic information |
| `campaign_desc.csv` | Campaign descriptions, types and duration |
| `campaign_table.csv` | Campaign assignments for individual households |
| `coupon.csv` | Coupon-to-product mapping information |
| `coupon_redempt.csv` | Household coupon redemption records |
| `causal_data.csv` | Weekly product display and mailer information |
